# 🎓 React Academy

A modern and responsive educational website built with **React.js** and **Vite**. React Academy is designed to provide beginner-friendly courses in React.js, JavaScript, and Web Development.

## 📚 Available Courses

### ⚛️ React.js Basics
Learn the fundamentals of React.js, including:

- Components
- Props
- State
- Hooks
- Basic React concepts

### 🟨 JavaScript Fundamentals
Learn modern JavaScript concepts such as:

- Variables
- Functions
- Arrays
- Objects
- ES6+ syntax

### 🌐 Web Development
Learn the fundamentals of building responsive websites using:

- HTML5
- CSS3
- Responsive Design
- Modern Web Development practices
